# Drop50 v2 — spec

Single user (36M, 255 → 205 lb). iPhone 17 Pro, home-screen web app, used in the gym.
Core job: walk in, know the full-body session, log sets in one tap each, beat last time.
Source framework: trainer.neal "Lean in 90 days" screenshots (3×/week full body, 90-day progression, diet formula, 10k steps).

## 1. Training program (plan.json v2)

**Session template** — every session hits six slots (trainer.neal full-body day):
A Squat · B Hinge · C Vertical push · D Horizontal push · E Pull (vertical or horizontal) · F Arms (biceps + triceps, superset).
Optional finisher on Day 2 (lateral raise) and Day 3 (seated hamstring curl), 2 sets.

**Variety** — 3-week rotation = 9 distinct sessions (W1D1 … W3D3), then repeats. Every exercise recurs within 2–5 sessions so "last time" stays recent.

New exercises (14): hack squat, back extension, hip thrust, machine shoulder press, Arnold press, incline DB press, machine chest press, one-arm DB row, close-grip pulldown, hammer curl, incline DB curl, rope pushdown, overhead rope extension, machine dip.
Every exercise has: name, slot, equipment, load basis ("each" for dumbbells, "total" otherwise), increment (5 lb default), cues (3), common mistake, swap list (= other exercises in the same slot).

**Sequence is completion-driven**: "today's workout" = the next unfinished session in the 9-session rotation. Missing a day never skips a workout. Training days (default Mon/Wed/Fri) only drive the week strip.

**Phases by date since start** (4-week months; week 13 closes 90 days, phase 3 continues after):
- Month 1 — Quality & form: compound slots A–E 3 × 8–12 @ 2–3 RIR; arms 3 × 10–12; finisher 2 × 12–15.
- Month 2 — Reverse pyramid: A–E set1 4–6, set2 8–10, set3 10–12, all @ 1–2 RIR; arms 3 × 10–12 @ 1–2 RIR.
- Month 3 — Intensity: same RPT, to (technical) failure; arms to failure. Cue: free-weight squats/hinges stop at the last clean rep.
Before the start date the app runs as a preview using Month 1.

## 2. Progression engine (pure, unit-tested `engine.js`)

History lookup: most recent completed set data for that exercise id, across all sessions (swaps included).
- **Straight sets**: no history → weight blank, target reps = bottom of range, note "Pick a weight you'd stop at with 2–3 left".
  All sets hit top of range → weight + increment, reps reset to bottom. Otherwise same weight, each set target = last reps + 1 (capped at top).
- **RPT**: per set index. If last exposure was RPT: hit top of that set's range → + increment, reps = bottom; else same weight, reps + 1.
  If last exposure was straight sets (Month 1→2 transition): set-1 weight from Epley e1RM of the best last set, solved for the bottom of 4–6 at target RIR; sets 2/3 = 90% / 80% of set 1. All rounded to the exercise increment.
  Live: entering set 1's weight recomputes set 2/3 targets (90/80%) unless they are already filled.
- Output per set: `{weight, reps, label}` plus a one-line "Last: 50 × 12, 12, 11 · Oct 19".

## 3. Data

localStorage key `drop50.v2` (migrate `drop50.v1`: keep profile + daily logs; old A/B/C workout data is dropped — the program had not started).
```
{ v:2, profile:{startDate:"2026-10-19", days:[1,3,5], startWeight, goalWeight, age, height, calories:2400, protein:180, stepGoal:10000},
  logs:{ "YYYY-MM-DD": {weight, steps, calories, protein} },
  sessions:[ {id, seq(0-8), cycle(n), date, startedAt, completedAt|null,
              entries:{ A:{exerciseId, sets:[{w, r, done}]}, …, F1, F2, X } } ],
  lastBackupAt }
```
`navigator.storage.persist()` requested on launch. One-tap backup via share sheet (`navigator.share({files})` → Files/iCloud Drive), download fallback. Backup nudge on the finish screen when last backup > 3 days. Import validates format. Settings → "Erase all data" (for the test week before the start date).

## 4. Experience (iPhone 17 Pro, 402 × 874 pt, Dynamic Island)

Home-screen app: manifest (standalone, portrait), apple-touch-icon, `black-translucent` status bar, safe-area insets everywhere, `100dvh`, 16px+ inputs (no focus zoom), `touch-action: manipulation`, no tap highlight, 44pt+ targets. Service worker precaches everything → works with no gym signal. Dark-first OLED black with one volt accent; light mode via tokens. SF Pro / SF Pro Rounded (system fonts), tabular numerals. iOS 26 glass (backdrop blur) on the floating tab bar, sheets and timer.

- **Today**: large date title; session card ("Week 2 · Day 1", Month badge, six slot rows with exercise names, ~55 min) and one big **Start workout** button (Resume if in progress). Daily tiles: steps (10k, 3k/4k/3k checkpoints), weight, calories, protein — tap → bottom sheet with large numeric entry. Week strip.
- **Workout (full-screen focus mode, no tab bar)**: progress dots, elapsed time, exercise cards in a vertical list, current card expanded. Card: real demo image (2-3 frame loop), name, slot tag, scheme ("3 × 8–12 · 2–3 RIR"), Last line, set rows `[#] [weight] [reps] [✓]` with ghost targets. **Tap ✓ on an empty row accepts the target** (one tap per set); edit numbers with the keypad. Checking a set: haptic tick (iOS switch trick, feature-detected), auto rest timer (2:30 compounds, 1:30 arms/finisher) as a floating glass pill under the Dynamic Island with −15/+15/skip; chime when done if audio unlocked. Completing all sets advances to the next card. **Swap** opens a sheet with same-slot alternatives (machine taken). Form cues behind a "Form" disclosure. Screen Wake Lock while in a session. **Finish** → summary: sets done, lifts that beat last time, backup button.
- **Progress**: weight chart (daily dots + 7-day average line, goal line), lb lost; sessions done, current week streak; per-exercise list with best recent set and e1RM sparkline; tap → set history.
- **Plan**: 90-day timeline (3 months, rules), 3-week rotation grid, diet (calorie target; macro ranges computed from the trainer's formula on goal weight: protein 1.8–2.2 g/kg, carbs 2–4 g/kg, fat 0.6–1 g/kg), foods list + 3 sample meal days, 10k step split, the one rule. Settings sheet: profile, start date, training days, backup/import/erase.

Motion: 200–300ms spring-ish ease, respects `prefers-reduced-motion`.

## 7. Review changes (Opus review, 2026-10-11)

- ✓ is blocked until a weight exists; reps have −/+ steppers so a one-tap check never logs a fake target.
- Only *full* exposures (every prescribed set done) drive progression; a partial one says "repeat the weight".
- Straight sets use classic double progression (add load only when every set hit the top). RPT is per set and
  each back-off stays one increment lighter than the set before it. Transition e1RM uses reps + RIR.
- Load basis per exercise: each / single / total / added (bodyweight +); unilateral lifts say "per side";
  weight jumps editable per exercise (Form tips).
- Arms are one superset card (1a/1b rows); rest starts after the pair.
- Unfinished sessions: End early (counts) / Discard (doesn't). Older than 12 h → banner on Today.
- iOS: SW update checked on every foreground, "Update now" banner, `cache:'reload'` precache;
  rest timer is end-time based; Wake Lock re-acquired on visibility; audio session ambient;
  install-first banner (home-screen app storage is separate from Safari); local-time dates only.
- Cut for v2: light mode, sparklines.
